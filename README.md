# ИИ-редактор

Скилл для Claude, ChatGPT и других ИИ-агентов: пишет, редактирует, сокращает и вычитывает тексты на русском. Бережёт факты и голос автора, убирает воду, канцелярит и ИИ-штампы и не давит на читателя ложной срочностью.

Скилл можно поставить в Claude, ChatGPT, Codex и другие среды. Редактор подключается сам, когда вы просите поработать с текстом: отдельный чат или промпт не нужен.

## Что умеет

- **Пишет** посты, статьи, письма, рассылки, лендинги, тексты интерфейсов, пуши и заголовки по вашим вводным.
- **Редактирует и сокращает**: убирает лишнее и сохраняет факты, структуру и интонацию автора.
- **Вычитывает**: исправляет только орфографию, пунктуацию, речевые ошибки и типографику.
- **Понимает неформальные просьбы**: «убери воду», «причеши», «проверь ошибки».
- **Не выдумывает**: не добавляет цифры, условия и обещания, которых нет во вводных, и спрашивает, если без них не обойтись.

Скилл подключается и тогда, когда ИИ пишет на русском длинный ответ — разбор, исследование, аналитику. Он дополняет ваши собственные правила стиля и не отменяет их.

## Установка

### Claude — веб и десктоп

1. Скачайте `ai-editor.zip` со страницы [Releases](https://github.com/vskrokha/ai-editor/releases/latest).
2. Откройте **Settings → Capabilities → Skills** и загрузите архив.

### Claude Code

```
/plugin marketplace add vskrokha/ai-editor
/plugin install ai-editor@vskrokha
```

Можно и вручную: скопировать папку `skills/ai-editor` в `~/.claude/skills/`.

### ChatGPT

1. Скачайте `ai-editor.zip` со страницы [Releases](https://github.com/vskrokha/ai-editor/releases/latest).
2. В боковой панели откройте **Plugins → Skills → Create → Upload from your computer** и загрузите архив.

Загрузка своих скиллов доступна не на всех тарифах и в рабочих пространствах может быть отключена администратором. Если такого пункта нет, воспользуйтесь способом из раздела «Другие чаты».

### Codex и другие агенты с поддержкой Agent Skills

Скилл написан в открытом формате [Agent Skills](https://agentskills.io). Скопируйте папку `skills/ai-editor` в каталог скиллов вашего агента: где он находится, написано в документации агента.

### Другие чаты — DeepSeek, Custom GPT, проекты

Если среда не поддерживает скиллы, вставьте текст из [`prompt/ai-editor.md`](prompt/ai-editor.md) в системный промпт, пользовательские инструкции или инструкции проекта.

## Как получить хороший результат

Расскажите в запросе о задаче, аудитории, формате и цели текста. Если приложите свои прошлые тексты, редактор постарается сохранить ваш голос.

## Структура репозитория

```
skills/ai-editor/SKILL.md   — сам скилл
prompt/ai-editor.md         — тот же текст в виде промпта для сред без скиллов
plugin.json                 — манифест плагина для ChatGPT и Codex
.claude-plugin/             — манифест плагина и маркетплейса для Claude Code
```
